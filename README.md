# parla! 🇮🇹

Eine interaktive Italienisch-Lernapp für deutschsprachige Anfänger.

Ziel: Italienisch von A0 bis B2 lernen – mit spielerischen Übungen, Grammatik, Aussprachetraining und Alltagssituationen auf Sardinien.

Die App soll für Smartphones optimiert sein und mit React, TypeScript und Tailwind CSS entwickelt werden.
